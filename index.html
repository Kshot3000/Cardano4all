Tools — right here, no wallet needed

Address inspector

Paste any Cardano address. Checks the bech32 checksum locally in your browser and tells you the address type and network. Nothing is sent anywhere.

ADA ⇄ lovelace converter

1 ADA = 1,000,000 lovelace. Exact integer maths (BigInt) — no floating-point rounding, works offline.

Epoch / slot calculator

Convert between Cardano mainnet slots and epochs, offline, from the fixed protocol parameters: Byron epochs held 21,600 slots of 20 seconds; since Shelley (epoch 208, slot 4,492,800) an epoch holds 432,000 slots of 1 second.

Staking rewards estimator

Model a stake at an annual rate you assume. A Cardano epoch is 5 days, so a year holds 73 epochs; the rate is split evenly across them and compounded each epoch in exact integer lovelace maths. A modelled estimate only — actual pool rewards vary with performance, saturation and fees, and are never promised.

Transaction fee calculator

Cardano's minimum fee is a fixed protocol formula: 44 lovelace per byte of transaction size + 155,381 lovelace (mainnet parameters, checked against the live protocol parameters for epoch 660). Enter a transaction size — your wallet or cardano-cli reports it when building — and get the exact minimum in lovelace.

Size-based minimum only: transactions that run Plutus scripts also pay for execution units, and reference scripts add a per-byte charge, so real script transactions cost more than this floor.
